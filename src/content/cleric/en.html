The Cleric is the healer, but while leveling it plays as a ranged damage dealer: {{ s('chain-of-torment') }} marks the target, {{ s('condemnation') }} punishes it, and the passive {{ s('radiant-benediction') }} heals you and the party on every hit. Heal only when you need to.

Leveling in one sentence

Hold {{ s('earths-retribution') }} for mana, spam the Chain line with the in-game macro, and put your skill points into attacks rather than heals.

{% endcall %} {% call section('fight-lvl', t.lvl_combat, 'lvl') %}
  • Packs: {{ s('chain-of-torment') }} (hits up to 4) → {{ s('condemnation') }} → {{ s('divine-aura') }} with the AoE pick → {{ s('judgment-thunder') }}.
  • Elites: {{ s('debilitating-mark') }} (lower Defense) → {{ s('chain-of-torment') }} → {{ s('bolt') }} charged → {{ s('condemnation') }}.
  • Mana: target mode, and weave {{ s('earths-retribution') }} — it restores MP on every cast.
  • Low HP: {{ s('healing-light') }}, and {{ s('radiant-benediction') }} keeps ticking as long as you hit.
  • Staggered bosses: {{ s('lightning-strike-scattershot') }} only works while the target is staggered.

Grobs' early-game setup: one hotbar line and a one-slot in-game macro. In AION 2 the bottom slot of a line has the highest priority — the card shows the line top to bottom as in the game.

{% call hotline('RMB', 'Chain line', ['chain-of-torment', 'debilitating-mark', 'condemnation', 'judgment-thunder']) %}Chain of Torment goes first so Condemnation can hit; Judgment Thunder has no cooldown and fills the gaps.{% endcall %}
