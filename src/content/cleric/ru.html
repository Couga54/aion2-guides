В подземельях AION 2 Целитель — лекарь, который обязан наносить урон: награда зависит от вклада, и Целитель, который только лечит, может остаться ни с чем. У группы хватает своих уклонений и неуязвимостей — подлечивай тех, кто только что получил урон, а всё остальное вкладывай в урон.

Билд в одном предложении

{{ s('earth-punishment') }} делает {{ s('condemnation') }} всегда критическим, а крит сбрасывает Приговор — так он бьёт без перезарядки, а {{ s('divine-aura') }}, {{ s('bolt') }} и {{ s('noble-aura') }} добавляют урон сверху.

Режим построен на PvE-гайде Kaeria по Целителю (на русском, записан на тайваньском клиенте; по её словам, подходит и для глобалки). Выбор скиллов бесплатно меняется в один клик — ресурсы стоят только арканы.

С Чародеем в группе: вместо Света спасения ставь любой хил или Воскрешение. Крик смерти (−15% сопротивления криту у босса на 15) — вариант для святилищ со вторым хилом; Всплеск энергии — только если группе не хватает ошеломления.

{% endcall %} {% call section('macro', 'Макрос', 'pve') %}

Kaeria использует только встроенный макрос, без стороннего софта, — так между шагами макроса можно нажимать хилы.

  • ДержатьВстроенный макрос на ПКМ вместе с клавишей линии базовой атаки (у неё это 3).
  • Ошеломление{{ s('lightning-strike-scattershot') }} стоит в макросе: когда босс ошеломлён, отпусти клавишу базовой атаки и держи только макрос.
  • ВручнуюХил тому, кто только что получил урон, полностью заряженный {{ s('bolt') }}, {{ s('prayer-of-amplification') }} по откату.

Точные линии на кнопках видны только на экране в видео. На глобалке с меньшим пингом можно чаще вплетать Возмездие земли.

  • Кольца: скрафти как можно раньше — у крафтовых колец на одну строку больше под активные скиллы.

  • Daevanion: сначала оранжевые узлы перезарядки и скорости боя, затем атака и крит, потом синие узлы скиллов, в конце защита.

Целитель — лекарь, но на прокачке он играет как дальнобойный боец: {{ s('chain-of-torment') }} метит цель, {{ s('condemnation') }} добивает её, а пассивка {{ s('radiant-benediction') }} лечит тебя и группу при каждом попадании. Лечись только когда нужно.

Прокачка в одном предложении

Держи {{ s('earths-retribution') }} ради маны, крути линию Цепи встроенным макросом и вкладывай очки навыков в атаки, а не в лечение.

{% endcall %} {% call section('fight-lvl', t.lvl_combat, 'lvl') %}
  • Пачки: {{ s('chain-of-torment') }} (бьёт до 4 целей) → {{ s('condemnation') }} → {{ s('divine-aura') }} со специализацией на АоЕ → {{ s('judgment-thunder') }}.
  • Элитки: {{ s('debilitating-mark') }} (снижает защиту) → {{ s('chain-of-torment') }} → заряженный {{ s('bolt') }} → {{ s('condemnation') }}.
  • Мана: режим с таргетом и {{ s('earths-retribution') }} между скиллами — он восполняет ману каждым кастом.
  • Мало ОЗ: {{ s('healing-light') }}, а {{ s('radiant-benediction') }} лечит, пока ты бьёшь.
  • Ошеломлённый босс: {{ s('lightning-strike-scattershot') }} работает только пока цель ошеломлена.
{% endcall %} {% call section('macro-lvl', 'Макрос на прокачке', 'lvl') %}
