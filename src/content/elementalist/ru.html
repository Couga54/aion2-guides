Заклинатель (Spiritmaster) — единственный призыватель: рядом с тобой сражается дух, каждый его скилл даёт элемент, а на четырёх элементах готов {{ s('elemental-fusion') }}. {{ s('dimensional-control') }} срабатывает каждый раз, когда дух использует скилл, а проклятия продолжают тикать на цели.

Прокачка в одном предложении

Качайся с {{ s('summon-water-spirit') }} (урон и мана), держи {{ s('cold-shock') }} ради маны, а встроенный макрос пусть крутит линию духов и линию Синтеза.

{% endcall %} {% call section('fight-lvl', t.lvl_combat, 'lvl') %}
  • Дух: {{ s('summon-water-spirit') }} до самого капа — лучший урон по одной цели и подпитка маной. Остальные на прокачке держатся на 1 уровне.
  • Пачки: {{ s('jointstrike-curse') }} (бьёт до 4 целей) → {{ s('combustion') }} → {{ s('elemental-fusion') }} со специализацией на АоЕ, когда он готов.
  • Мана: главная проблема на старте — режим с таргетом, {{ s('cold-shock') }} между скиллами и ротация духов, которая заканчивается на Духе воды.
  • Ошеломлённые цели: {{ s('rapid-scattershot') }}.
  • {{ s('souls-cry') }} не качай — это PvP-скилл.
{% endcall %} {% call section('macro-lvl', 'Макрос на прокачке', 'lvl') %}

Стартовая настройка Grobs: две линии на кнопках и встроенный макрос из двух слотов. В AION 2 наивысший приоритет у нижнего слота линии — карточки показывают линии сверху вниз, как в игре.

{% call hotline('1', 'Линия духов', ['summon-water-spirit', 'jointstrike-corrode', 'summon-earth-spirit', 'summon-fire-spirit']) %}Сначала Дух воды; Кооперация: Разложение (стигма) заставляет цель получать больше урона от духа.{% endcall %} {% call hotline('2', 'Линия Синтеза', ['elemental-fusion', 'dimensional-control', 'jointstrike-curse', 'combustion']) %}Синтез элементов и Повелитель пространства срабатывают, как только духи их открывают; Воспламенение заполняет паузы.{% endcall %}

Встроенный макрос (окно скиллов → Макрос), задержка 10 мс в каждом слоте:
